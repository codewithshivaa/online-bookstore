# 📚 Online Bookstore Web Application

## 📌 Description
An online bookstore web application where users can browse, search, and purchase books seamlessly. The platform provides secure authentication, cart functionality, and order management with a responsive UI.

---

## 🚀 Features
- 📖 Browse and search books  
- 🛒 Add to cart and manage cart  
- ❤️ Add to favourites  
- 🔐 User authentication (Login & Signup)  
- 📦 Order placement and history  
- 🧑‍💼 Admin panel for managing books and orders  
- 📱 Responsive design  

---

## 🛠️ Tech Stack

### 💻 Frontend
- React.js (Vite)
- Tailwind CSS
- JavaScript

### ⚙️ Backend
- Node.js
- Express.js

### 🗄️ Database
- MongoDB

## ⚙️ Installation & Setup

### 1. Clone Repository

git clone https://github.com/codewithshivaa/online-bookstore.git
cd online-bookstore


### 2. Backend Setup

cd backend
npm install
npm start


### 3. Frontend Setup

cd frontend
npm install
npm run dev


---

## 🔐 Environment Variables

Create a `.env` file in backend folder:


MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
